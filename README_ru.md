# Umbrage

[English](./README.md) | [Русский](./README_ru.md)

Umbrage это кроссплатформенный GUI инструмент для работы с устройствами на базе SOC MediaTek, основанный на базе ядра [penumbra](https://github.com/shomykohai/penumbra) v2.0.

Проект нацелен на то, чтобы сделать рутинные и сложные задачи вроде разблокировки загрузчика или прошивки максимально простыми и доступными каждому, избавляя от необходимости разбираться в терминале и скриптах.

Главная цель проекта заключается в создании открытой и сильной альтернативы существующим платным утилитам, которая будет постоянно развивается за счет поддержки и вклада сообщества.

## Возможности

### Пошаговый и минималистичный UX

В отличие от классических громоздких GSM-инструментов, перегруженных тысячей кнопок и лишних элементов на экране, Umbrage делает ставку на чистый интерфейс.

Процесс выстроен последовательно: приложение скрывает всё лишнее на текущем этапе и проводит пользователя по шагам - например, последовательно запрашивая необходимые файлы _(DA -> AUTH -> PRELOADER)_.

### Шаблоны сообщества

Зачем долго искать файлы в интернете, если можно использовать пользовательский репозиторий Umbrage?

В нём собрана огромная база DA, AUTH и PRELOADER файлов, аккуратно отсортированных по устройствам и проверенных сообществом. Просто укажите модель своего устройства и выберите один из готовых шаблонов.

> Это работает ровно так же, как и в платных GSM-инструментах, но гораздо круче, гибче и полностью бесплатно!

## Установка

### Linux

Скачайте [последний релиз](https://github.com/progzone122/umbrage/releases), запустите Umbrage в терминале и просто следуйте инструкциям на экране!

```shell
./umbrage-linux.AppImage
```

### MacOS

1. Установите qt6

```shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" && brew install qt
```

2. Скачайте [последний релиз](https://github.com/progzone122/umbrage/releases), запустите Umbrage в терминале **с повышенными привелегиями** и просто следуйте инструкциям на экране!

```shell
sudo ./umbrage-macos-arm
```

### Microslop Windows

> ⚠️ **ВНИМАНИЕ!**
>
> **Использование Windows настоятельно НЕ рекомендуется**

Umbrage на данный момент не предоставляет готовые бинарники для Windows, **потому что заставить эту еб\*чую слоп систему нормально работать с MediaTek-устройствами - игра в жанре соулс лайк на хардкоре.**

**НЕ ИСПОЛЬЗУЙТЕ WINDOWS! ТОЛЬКО ЕСЛИ РАДИ МАЗОХИЗМА! НЕ ПЛАЧЬТЕ ПОТОМ!**

Если вы всё-таки решили страдать - [скомпилируйте](CONTRIBUTING.md) из исходников `umbrage-setup.exe` и запустите его, чтобы установить Umbrage.

`libusb` уже встроен в бинарник, **но подходящий драйвер для USB-интерфейса MediaTek автоматически не устанавливается.**

Установите **WinUSB** один раз через [Zadig](https://zadig.akeo.ie/):

1. Подключите устройство в режиме **BROM / Preloader / DA**.
2. Откройте Zadig и выберите появившийся USB-интерфейс устройства.
3. В качестве драйвера выберите **WinUSB**.
4. Установите драйвер.

**И ДЕЛАЙТЕ ЭТО БЫСТРО.**

Устройство может находиться в BROM/Preloader всего ограниченное время, после чего оно просто исчезнет из системы. Поэтому вам нужно успеть выбрать нужный USB-интерфейс в Zadig и установить драйвер, пока устройство ещё определяется.

После этого Umbrage сможет получить доступ к устройству через `libusb` **(Наверное, зависит от настроения индусов)**.

_Это довольно просто, не так ли?_

## Вклад

Вы можете внести свой вклад в проект двумя ключевыми способами:

- **Первый и самый очевидный** - это прямой вклад в разработку Umbrage.
- **Вторым**, не менее ценным вкладом станет развитие [репозитория шаблонов umbrage](https://github.com/progzone122/umbrage-repo), который играет очень важную роль в проекте и всей экосистеме Umbrage.

Инструкции по сборке и другую инфу, полезную для разработки, смотрите в [CONTRIBUTING.md](./CONTRIBUTING.md)

### Использование ИИ

Искусственный интеллект разрешено использовать в качестве помощника, однако вы должны полностью понимать каждую вносимую им правку и нести за неё полную личную ответственность.

PR, написанные по принципу «вайбкода» _(бездумно скопированный и не проверенный код)_, будут без колебаний закрываться.

За систематические нарушения возможна перманентная блокировка во всех репозиториях проекта Umbrage.
